Pertanyaan Sering Diajukan (FAQ)

Informasi penting seputar penggunaan platform Rekan Ajar AI

Apakah dokumen hasil penyusunan sesuai standar BSKAP resmi?

Ya, 100% sesuai. Seluruh alur sistem dirancang khusus mematuhi struktur BSKAP Kemendikbudristek Kurikulum Merdeka terkini, mencakup pemetaan CP, TP/ATP, Capaian Dimensi Profil Pelajar Pancasila (P3), hingga Rubrik Asesmen Analitik.

Apakah Saldo Token memiliki masa kedaluwarsa?

Tidak ada. Token yang Bapak/Ibu miliki atau beli bersifat permanen dan tanpa tanggal kedaluwarsa. Bapak/Ibu dapat menggunakannya kapan saja sesuai kebutuhan penyusunan administrasi sekolah.

Bagaimana cara mengedit hasil dokumen di Microsoft Word?

Cukup klik tombol .DOCX pada panel editor. Dokumen akan terunduh otomatis dalam format .DOCX modern yang rapi, utuh, dan siap diedit di Microsoft Word versi berapa pun.

Apakah data siswa dan dokumen saya aman tersimpan?

Sangat aman. Seluruh data tersimpan di server Cloud Supabase terenkripsi dengan perlindungan Row Level Security (RLS). Hanya akun Bapak/Ibu yang memiliki hak akses untuk membaca dan mengelola dokumen tersebut.
